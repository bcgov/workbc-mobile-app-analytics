# WorkBC mobile app analytics API

Backend API for collecting and serving analytics events from the WorkBC mobile application.

## Stack

- **Runtime:** Node.js  
- **Framework:** [Hono](https://hono.dev/) with **TypeScript** (application scaffold lands in [Session 2](./IMPLEMENTATION_PLAN.md#session-2--application-skeleton-hono-typescript-versioned-api) per the implementation plan)

## Run locally

Local install, scripts, and quality gates are defined in **Session 4** of [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md). Until then, clone this repository and follow that plan for the next milestones.

## Repository

- **Remote:** `https://github.com/bcgov/workbc-mobile-app-analytics`  
- **Default branch:** `main`
